# Configuration Reference

All configuration is done through the `.env` file. Copy `.env.example` to `.env` and customize the values.

---

## Database

| Variable | Default | Description |
|---|---|---|
| `DB_NAME` | `mywifipass` | PostgreSQL database name |
| `DB_USER` | `mywifipass_user` | Database user |
| `DB_PASS` | *(required)* | Database password |
| `DB_HOST` | `database` (Docker) | Database hostname. Do not change in Docker; use `localhost` for manual development |

---

## Server & Network

| Variable | Default | Description |
|---|---|---|
| `DOMAIN` | `domain.example.com` | Public domain or `IP:port` for the server. Used to build absolute URLs in emails and QR codes |
| `SERVER_IP` | *(required)* | IP address of the server. Automatically added to `ALLOWED_HOSTS` |
| `ALLOWED_HOSTS` | `localhost,127.0.0.1` | Comma-separated list of allowed hostnames. `DOMAIN` and `SERVER_IP` are added automatically |
| `WEBAPP_PORT` | `10000` | Host port mapped to container port 8000 |
| `RADIUS_PORT` | `1812` | Host port mapped to container UDP port 1812 |
| `RADIUS_CLIENT_IP` | `*` | IP or subnet of the access point(s). Use `*` to allow any |
| `DEBUG` | `False` | Enable Django debug mode. **Never enable in production** |
| `SSL` | `False` | Enable HTTPS. When `True`, sets `SECURE_SSL_REDIRECT`, `SESSION_COOKIE_SECURE`, and `CSRF_COOKIE_SECURE` |
| `TZ` | `Europe/Madrid` | Server timezone. Used for date calculations and scheduling |
| `DJANGO_SECRET_KEY` | *(auto-generated)* | Django cryptographic signing key. Auto-generated by entrypoint if not set |
| `CSRF_TRUSTED_ORIGINS` | *(auto-generated)* | CSRF trusted origins. Automatically populated from `ALLOWED_HOSTS` |

### SSL / Reverse Proxy

If you use a reverse proxy (NGINX, Traefik, Caddy) that terminates SSL:

```ini
SSL=True
# The proxy must set the X-Forwarded-Proto header
```

The configured `SECURE_PROXY_SSL_HEADER` is `('HTTP_X_FORWARDED_PROTO', 'https')`.

## Email (SMTP)

| Variable | Default | Description |
|---|---|---|
| `EMAIL_HOST_USER` | *(required)* | SMTP sender email address |
| `EMAIL_HOST_PASSWORD` | *(required)* | SMTP password or app password |
| `EMAIL_HOST` | `smtp.gmail.com` | SMTP server hostname |
| `EMAIL_HOST_PORT` | `587` | SMTP server port |
| `EMAIL_USE_TLS` | `True` | Use TLS for SMTP connection |
| `MYWIFIPASS_FROM_NAME` | `MyWifiPass` | Display name for the `From` header in outbound emails |
| `MYWIFIPASS_PLAYSTORE_URL` | Play Store URL | Link to the Android app in Google Play, included in registration emails |
| `EMAIL_TIMEOUT` | `5` | Connection timeout for SMTP (hardcoded in settings) |

### Gmail Setup

1. Enable 2-Step Verification on your Google Account
2. Generate an [App Password](https://myaccount.google.com/apppasswords)
3. Use that 16-character password as `EMAIL_HOST_PASSWORD`

### Email Delivery Mechanism

Emails are sent as multipart MIME messages with:
- Plain text body (for clients without HTML support)
- HTML body with inline QR code (via Content-ID, not as attachment)
- QR code included as `MIMEImage` with `Content-ID: <qr_wifi_pass>`

A fallback mechanism uses Django's built-in `EmailMultiAlternatives` if the raw MIME send fails. All emails are sent from a background thread to avoid blocking the HTTP response.

## RADIUS Certificate Directory

| Variable | Default | Description |
|---|---|---|
| `RADIUS_CERT_DIR` | `/djangox509/mywifipass/server_certs` | Directory where certificates are exported for RADIUS (shared Docker volume) |

The subdirectories `pending/`, `processed/`, `deletion/`, and `update_crl/` are created automatically.

## FIDO2 / WebAuthn

| Variable | Default | Description |
|---|---|---|
| `ANDROID_ADDITIONAL_ORIGINS` | *(empty)* | Additional Android app key hashes (comma-separated). Format: `android:apk-key-hash:HASH1,android:apk-key-hash:HASH2` |
| `ANDROID_ADDITIONAL_APPS` | *(empty)* | Additional Android apps for Digital Asset Links. JSON array with objects containing `package_name` and `sha256` |

The official MyWifiPass app (`app.mywifipass`) is **always included by default** with both release and debug key hashes. The additional variables allow custom-compiled app variants.

### RP (Relying Party) Configuration

The FIDO2 Relying Party is derived from `DOMAIN` and `SSL`:

```python
RP_ID = DOMAIN.split(':')[0]  # Hostname without port
RP_NAME = 'MyWifiPass'
ORIGIN = f'{"https" if SSL else "http"}://{DOMAIN}'
EXPECTED_ORIGINS = [
    f"https://{DOMAIN}",
    f"http://{DOMAIN}",
    'android:apk-key-hash:IuZTSult...',  # Release key
    'android:apk-key-hash:mn_EqHb9...',  # Debug key
]
```

## Django Application Settings

### Installed Apps

```python
INSTALLED_APPS = [
    'django.contrib.admin',
    'django.contrib.auth',
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',
    'django_x509',           # PKI library (fork of OpenWISP django-x509)
    'rest_framework',         # Django REST Framework
    'rest_framework.authtoken',
    'drf_yasg',              # Swagger / OpenAPI docs
    'mywifipass',            # Main application
    'fido2_poc',             # FIDO2/WebAuthn sidecar app
]
```

### REST Framework

```python
DEFAULT_AUTHENTICATION_CLASSES = [
    'rest_framework.authentication.TokenAuthentication',   # Stateless APIs
    'rest_framework.authentication.SessionAuthentication',  # Browser access
]
DEFAULT_PERMISSION_CLASSES = ['IsAuthenticated']
```

### Static & Media Files

- **Static files** served by WhiteNoise (`whitenoise.middleware.WhiteNoiseMiddleware`)
- **Media files** (logos) stored in `logos/` directory, served at `/logos/`

### Logging

Logs are sent to stdout (Docker-compatible). Log levels:
- `django` logger: `INFO`
- `fido2_poc` logger: `DEBUG` when `DEBUG=True`, `INFO` otherwise

### Internationalization

- `LANGUAGE_CODE`: `en-us`
- `USE_I18N`: `False`
- `USE_TZ`: `True` (timezone-aware datetimes)
- `TIME_ZONE`: from `TZ` env var

## Rate Limiting (Throttles)

Configured in `settings.py` via `REST_FRAMEWORK['DEFAULT_THROTTLE_RATES']`:

| Scope | Limit | Type | Description |
|---|---|---|---|
| `login_attempt` | 5/minute | Per IP (anon) | Login endpoint protection |
| `certificate_signing` | 3/minute | Per user | CSR signing is computationally expensive |
| `authorization` | 10/minute | Per user | Admin authorization rate |
| `download` | 20/minute | Per IP (anon) | Wi-Fi pass download |
| `validation` | 10/minute | Per IP (anon) | User validation checks |

## Certificate Defaults (`django_x509/settings.py`)

These are the defaults used when generating CAs and certificates:

| Setting | Value |
|---|---|
| Key length | 2048 bits (RSA) |
| Digest algorithm | SHA-256 |
| CA validity | 3650 days (10 years) |
| Certificate validity | 365 days |

The CA validity for a network is determined by the network's `start_date` and `end_date` fields, which are converted to end-of-day to prevent premature expiration.

## Complete `.env.example`

```ini
#### MYWIFIPASS CONFIG VARIABLES

RADIUS_CLIENT_IP=*
RADIUS_PORT=1812

DB_NAME=mywifipass
DB_USER=mywifipass_user
DB_PASS=your_database_password

EMAIL_HOST_USER=your_email@gmail.com
EMAIL_HOST_PASSWORD="your_app_password"
EMAIL_USE_TLS=True
EMAIL_HOST=smtp.gmail.com
EMAIL_HOST_PORT=587

MYWIFIPASS_FROM_NAME=MyWifiPass
MYWIFIPASS_PLAYSTORE_URL=https://play.google.com/store/apps/details?id=app.mywifipass

WEBAPP_PORT=10000
DOMAIN=domain.example.com
SERVER_IP=X.X.X.X
ALLOWED_HOSTS=domain.example.com

DEBUG=False
SSL=False
TZ="Europe/Madrid"

#### FIDO2 CONFIGURATION (Optional - for Android app support)

ANDROID_ADDITIONAL_ORIGINS=
ANDROID_ADDITIONAL_APPS=
```
